# IFLOW контекст: Панель управления Telegram-ботом

## Обзор проекта

Это веб-панель управления, написанная на PHP, для администрирования Telegram-бота. Панель подключается к базе данных PostgreSQL и предоставляет удобный интерфейс для управления различными аспектами функционирования бота в нескольких чатах.

### Основные возможности

*   **Аутентификация пользователей**: Безопасный вход через пароль с использованием хэширования (bcrypt)
*   **Управление чатами**: Централизованное управление несколькими чатами Telegram с карточным интерфейсом
*   **Команды помощника (Helper Commands)**: Настройка пользовательских команд с автоматическими ответами и настраиваемой задержкой
*   **Действия RP (RP Actions)**: Управление действиями ролевой игры и их реакциями
*   **Строковое содержимое (String Content)**: Управление текстовыми шаблонами для различных сценариев:
    *   Слова для удаления
    *   Слова профиля
    *   Прощальные слова
    *   Случайные ответы на Ping
    *   Ping слова
    *   Случайные первые фразы

## Технологический стек

*   **Язык бэкенда**: PHP 8.x
*   **База данных**: PostgreSQL
*   **Фронтенд**: HTML5, CSS3, JavaScript
*   **Веб-сервер**: Требуется сервер с поддержкой PHP и PostgreSQL (Apache, Nginx)

## Структура проекта

### Основные файлы

*   `index.php` - Главная страница с карточками чатов
*   `login.php` - Страница аутентификации
*   `logout.php` - Выход из системы
*   `generate_hash.php` - Утилита для генерации хэшей паролей

### Модули управления

#### Helper Commands
*   `helper.php` - Просмотр команд помощника
*   `add_helper.php` - Добавление новой команды
*   `edit_helper.php` - Редактирование существующей команды

#### RP Actions
*   `rp_actions.php` - Просмотр RP действий
*   `add_rp_actions.php` - Добавление нового RP действия
*   `edit_rp_actions.php` - Редактирование существующего RP действия

#### String Content
*   `str_content.php` - Просмотр строкового содержимого с функцией сортировки
*   `add_str_content.php` - Добавление нового строкового содержимого
*   `edit_str_content.php` - Редактирование существующего содержимого

### Директория `elems/`

*   `layout.php` - Общий шаблон макета для всех страниц
*   `init.php` - Инициализация соединения с базой данных и сессий
*   `info.php` - Компонент для отображения системных сообщений

### Директория `old/`

Содержит резервные копии и предыдущие версии файлов.

## Безопасность

### Аутентификация
*   Использование безопасного хэширования паролей (bcrypt/PASSWORD_DEFAULT)
*   Защита от session fixation через `session_regenerate_id(true)`
*   Проверка аутентификации на всех защищенных страницах

### Защита данных
*   Использование `htmlspecialchars()` для предотвращения XSS-атак
*   Проверка сессий перед доступом к административным функциям
*   Подключение к БД через переменные окружения

## Подключение к базе данных

Информация о подключении настраивается через переменные окружения:
*   `DB_HOST` - хост базы данных
*   `DB_PORT` - порт подключения
*   `DB_USER` - имя пользователя
*   `DB_PASSWORD` - пароль
*   `DB_NAME` - имя базы данных

Эти переменные считываются в файле `elems/init.php`.

## Особенности интерфейса

### Карточки чатов
Главная страница использует современный карточный интерфейс для отображения информации о чатах с группировкой ссылок по категориям:
*   Справка
*   Модерация
*   Вовлечение

### Сортировка данных
Страница `str_content.php` включает клиентскую сортировку таблиц по:
*   Строковым значениям
*   Булевым значениям (active/inactive)
*   Дате создания с локализацией времени

### Визуальные индикаторы
*   Использование эмодзи для обозначения статуса (✅/❌)
*   Локализация времени в соответствии с часовым поясом пользователя

## Архитектура приложения

### Поток выполнения
1. Инициализация сессии и подключение к БД (`elems/init.php`)
2. Проверка аутентификации пользователя
3. Загрузка соответствующего модуля управления
4. Отображение данных через общий шаблон (`elems/layout.php`)
5. Обработка действий (CRUD операции) с перенаправлением

### Обработка ошибок
*   Включено отображение всех ошибок для разработки
*   Обработка ошибок подключения к БД
*   Системные сообщения об успехе/неудаче операций

## Запуск и развертывание

1.  Убедитесь, что веб-сервер установлен и настроен с расширениями PHP и PostgreSQL
2.  Настройте переменные окружения для подключения к базе данных
3.  Импортируйте структуру базы данных (таблицы: chats, helper, rp_actions, str_content, password_hash)
4.  Создайте хэш пароля администратора через `generate_hash.php`
5.  Разместите файлы проекта в корневом каталоге документов веб-сервера
6.  Убедитесь, что веб-сервер может читать и выполнять файлы PHP
7.  Откройте в браузере страницу `login.php` для входа

## Требования к серверу

*   PHP 8.x с расширением PostgreSQL
*   Сервер баз данных PostgreSQL
*   Веб-сервер (Apache или Nginx)
*   Настроенные переменные окружения для подключения к БД

## Примечания разработчика

*   Проект использует процедурный подход к программированию на PHP
*   Все SQL-запросы выполняются через функции `pg_query()` и `pg_fetch_array()`
*   Приложение спроектировано для работы в директории `/admin/` на веб-сервере
*   Используется UTF-8 кодировка для корректной работы с кириллицей
