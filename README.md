# telegram_bot
Телеграм бот для тематических чатов. Он работает как навигатор по тематическому контенту, удаляет спам, развлекает пользователей отвечая на игровые команды. Использует базу банных, имеет веб-интерфейс для работы с ней. Сейчас бот бослуживает 5 чатов на 15800, 700, 200, 80 и 18 пользователей.
